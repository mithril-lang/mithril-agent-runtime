# Scheduled profile cloud pilot

This opt-in pilot preserves one execution owner per profile. It is separate from
the API-only trial handoff and does not alter the placement of unenrolled agents.

The runtime artifact is an immutable pair: the registry image digest in
`wrangler.jsonc` and the SHA-256 code overlay generated by `build_overlay.py`.
The overlay is installed before starting the agent. Its entrypoint patching
fails if the pinned image does not expose the expected functions. Each actual
before/after source digest is reported by the private status endpoint. No user
profile or credential is included in the code overlay or image.

`profile_placement.execution` holds an OS lease across complete agent turns and
cron jobs, including script-only jobs. An enrolled source enters `draining`
before waiting for admitted work. New work is refused while admitted nested
work may finish. Exclusive freeze and SQLite online backup precede export.
The destination stages an authenticated encrypted capsule. It cannot activate
without the source's matching durable release proof. The owner identity is
bound to the host or the Container's stable Durable Object identity, so copying
an active profile to another runtime does not admit execution there.

The profile keeps its identity and cron definitions. Its own workspace paths
are mapped to Linux. Mac MCP processes are explicitly reported as unavailable;
they are never replaced by an implicit paid provider or another profile's
credential. Pilot inference and cron smoke validation do not establish that
those Mac-specific capabilities are qualified on Linux.

The control plane uses local SQLite in each Container, encrypted R2 checkpoints,
and independent object readback before acknowledging staged or activated state
and completed interactive requests. It does not use the unqualified D1 facade.
External Durable Object alarms wake only the assigned Container for cron. Sleep,
request failure and network partition never transfer ownership back to a Mac.

Acceptance requires the exact-source branch and integrated-main CircleCI run,
the live pinned-image overlay readback, ten actual inference and scheduled smoke
receipts, and ten controlled restart/history-recall and old-local-owner refusal
receipts. Existing source cron definitions must retain their IDs and schedules.
Real research-job completion is reported separately from the harmless smoke
jobs. No credential, raw profile archive or private conversation belongs in a
public CI artifact or PR.

This pilot establishes controlled restart recovery, not zero-loss background
crash recovery or general hostile multi-tenant shell isolation. Before stopping
a Container, finish its admitted work and independently checkpoint the resulting
state. Never replay a transfer with a different operation after an uncertain
release, erase a placement journal, or restore an old active owner as fallback.
